# AI Racing Evolution

A neuroevolution system that trains neural networks to drive racing cars using evolutionary optimization. Built with **C++** and **Raylib**.

```
Sensors → Neural Network → Action → Simulation → Fitness → Selection → Mutation → Repeat
```

Neural networks are trained by running 100 cars simultaneously, measuring fitness, selecting the best, and mutating copies to create the next generation. This is **not** gradient-based reinforcement learning — weights are modified directly through mutation rather than backpropagation.

The system uses progressive multi-map training: once enough cars finish a track, the best brains are carried forward to a harder map.

---

## Prerequisites

- **g++** (C++17 or later)
- **Raylib** (graphics library)
- **Linux** with X11 (tested on Ubuntu)

---

## Installing Raylib (Ubuntu / Debian)

### Option 1 — Build from source (recommended)

```bash
# Install build dependencies
sudo apt update
sudo apt install build-essential git cmake libasound2-dev \
    libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev \
    libglu1-mesa-dev libxcursor-dev libxinerama-dev \
    libwayland-dev libxkbcommon-dev

# Clone and build Raylib
git clone https://github.com/raysan5/raylib.git
cd raylib
mkdir build && cd build
cmake -DBUILD_SHARED_LIBS=OFF ..
make -j$(nproc)
sudo make install
```

This installs `libraylib.a` to `/usr/local/lib/` and `raylib.h` to `/usr/local/include/`.

### Option 2 — apt (if available)

```bash
sudo apt install libraylib-dev
```

> **Note:** The apt version may be older. Building from source gets you the latest.

## Building

There are **three programs** in this project. Each is compiled with a single `g++` command.

### 1. AI Racing (training)

This is the main training program. It runs the evolutionary algorithm across multiple maps and saves the final trained brains.

```bash
g++ -std=c++17 -O2 -o ai_racing \
    main.cpp Evolution.cpp Game.cpp NeuralNetwork.cpp \
    -I/usr/local/include -L/usr/local/lib \
    -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
```

### 2. Final Test (evaluation)

Loads the 5 trained brains from `final_brains.bin` and runs them on a test map **without** evolution. Use this to observe the learned driving behavior.

```bash
g++ -std=c++17 -O2 -o final_test \
    final_test.cpp Game.cpp NeuralNetwork.cpp \
    -I/usr/local/include -L/usr/local/lib \
    -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
```

### 3. Map Viewer (utility)

A standalone track preview tool. Paste coordinates into `map_viewer.cpp` to visually inspect a track before using it for training.

```bash
g++ -std=c++17 -O2 -o map_viewer \
    map_viewer.cpp \
    -I/usr/local/include -L/usr/local/lib \
    -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
```

---

## Running

```bash
# Train the AI (opens a window showing 100 cars racing)
./ai_racing

# After training completes (final_brains.bin is saved):
./final_test

# Preview a track layout:
./map_viewer
```

Training runs at 60 FPS. When all maps are cleared, the top 5 brains are saved to `final_brains.bin` and a "TRAINING COMPLETE" message appears.

Press **Esc** to close any window.

## Project Structure

| File | Purpose |
|------|---------|
| `main.cpp` | Training entry point — creates window and runs the evolution loop. |
| `Evolution.h / .cpp` | Evolutionary controller — population, selection, mutation, multi-map progression. |
| `Game.h / .cpp` | Racing environment — track, car physics, sensors, collision, fitness. |
| `NeuralNetwork.h / .cpp` | Feed-forward neural network — predict, mutate, save/load. |
| `final_test.cpp` | Post-training evaluation — loads saved brains and runs them. |
| `map_viewer.cpp` | Track preview utility. |
| `final_brains.bin` | Saved trained neural networks (generated by training). |
| `maps.txt` | Reference notes for map coordinates and mutation values. |

## Key Configuration Points

| What to change | Where |
|----------------|-------|
| Population size | `Evolution.h` → `populationSize` |
| Parent count / finisher threshold | `Evolution.h` → `parentCount` |
| Map coordinates | `Evolution.cpp` → `MapConfig::maps[]` |
| Number of maps | `Evolution.cpp` → `MapConfig::mapCount` |
| Mutation strength per map | `Evolution.cpp` → `MapConfig::mutationRanges[]` |
| Track width | `Game.cpp` constructor → `trackWidth` |
| Car size | `Game.cpp` constructor → `carRadius`, `carLength` |
| Time limit | `Game.cpp` → `update()`, `raceTime >= 30.0` |
| Sensor layout | `Game.cpp` → `getSensors()` |
| Action mapping | `Game.cpp` → `update()` switch block |
| Fitness formula | `Game.cpp` → `getFitness()` |
| NN architecture | `NeuralNetwork.h` → layer array dimensions |
| Physics tuning | `Game.cpp` → acceleration / friction / steering sections |
| Saved brains filename | `Evolution.cpp` → `saveFinalBrains()` |
| Test map for evaluation | `final_test.cpp` → `testMap[]` |

## How It Works

1. **100 neural networks** are created with random weights.
2. Each network controls a car in its own racing simulation.
3. Cars sense the track via **5 distance sensors** (forward, left, right, and two diagonals) plus their current **speed** — 6 inputs total.
4. The network produces **7 outputs** (one per driving action). The action with the highest activation is selected.
5. When a car crashes, finishes, or times out, its **fitness** is recorded.
6. After all 100 cars finish, the **top 5 by fitness** are preserved unchanged (elitism), and **95 children** are generated by mutating copies of those parents.
7. This repeats on the same map until a single generation produces **≥ 5 finishers**.
8. The 5 best finishers become the parents for the **next map**, where the process repeats with a smaller mutation range.
9. After all maps are cleared, the final 5 brains are saved to `final_brains.bin`.
